# MSc ICN Security Thesis  
## Attack Taxonomy, Countermeasures, and Access Control in Information-Centric Networking (ICN)

This repository contains my **Master’s thesis in Cyber Security**, focused on the **security challenges, attack taxonomy, mitigation strategies, and access control mechanisms in Information-Centric Networking (ICN)**.

The research provides a **comprehensive comparative analysis of ICN architectures**, identifies **major threat vectors**, and evaluates **practical countermeasures and secure access control models** to improve resilience, privacy, and trust in future network environments.
