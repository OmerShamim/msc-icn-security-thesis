# MSc ICN Security Thesis

## Attack Taxonomy, Countermeasures, and Access Control in Information-Centric Networking (ICN)

This repository contains the final version of my Master’s thesis in Cyber Security, focused on the security challenges, attack taxonomy, mitigation strategies, and access control mechanisms in Information-Centric Networking (ICN).

The work examines how ICN architectures differ from host-centric networking, analyzes the major threat vectors affecting ICN deployments, and evaluates practical mitigation techniques and secure access control models that can improve resilience and trust in content-centric environments.

## Overview

Information-Centric Networking is a networking paradigm that moves the focus from host-to-host communication toward named content, caching, and retrieval by identifiers. While this model offers advantages in scalability, efficiency, and mobility support, it also introduces novel security concerns.

This thesis investigates:

- The core security properties and vulnerabilities of ICN
- A taxonomy of ICN-specific attacks and threat surfaces
- Existing mitigation and defense strategies
- Access control models suitable for ICN environments
- Trade-offs between security, performance, and scalability

## Research Focus

The project explores the relationship between ICN design principles and security risks, with emphasis on:

- Content poisoning and cache manipulation
- Naming and routing attacks
- Interest flooding and DoS-related behaviors
- Privacy and trust concerns in content dissemination
- Policy-based and authorization-aware access control approaches

## Abstract

This thesis presents a structured analysis of Information-Centric Networking security by identifying key attack classes, evaluating mitigation mechanisms, and reviewing secure access control approaches. It highlights the need for robust security designs in content-centric networking systems and provides a comparative perspective on how ICN vulnerabilities can be addressed in practical deployments.
